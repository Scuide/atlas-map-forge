**Pre-release 0.6.0: maps for Beyond All Reason (experimental).** Atlas Map Forge makes complete, playable maps for Zero-K, and now also for [Beyond All Reason](https://www.beyondallreason.info): pick the game at the top of the app, and the same templates and the same editor build a BAR map, installed straight into BAR.

## Download

- **Windows:** `AtlasMapForge.exe` below: one file, no installation and no Python needed. Replace the old exe; your settings and project files stay.
- **Linux:** `AtlasMapForge-linux-x86_64.tar.gz` below: unpack it and start `./AtlasMapForge`. The app opens in your web browser (glibc 2.35 or newer, e.g. Ubuntu 22.04+).

The Windows program is not code-signed yet, so Windows SmartScreen will say "Windows protected your PC". Click **More info**, then **Run anyway**. Every program is built and tested automatically on GitHub from the public source code in this repository.

Website: https://scuide.github.io/atlas-map-forge/

## New in 0.6.0

- **Map for: Zero-K or Beyond All Reason.** A switch at the top of the app (also Settings > Game, and `atlasforge build <template> --game bar`).
- **BAR maps the way BAR reads them:** metal spots show and give the metal you set (tested in game), wrecks are BAR units, lava uses BAR's own lava settings, the volcano eruption uses BAR effects, and the map is installed into BAR's data folder with its picture in the map list.
- **BAR's map checklist:** BAR maps come as `.sd7`, keep wind (at most 30) and tidal strength (at most 25) in BAR's limits, light the map from the north and use the splat format BAR's guide asks for.
- **Checks per game:** "Where can it go?", the slope overlay and the check report use the movement rules of the chosen game. BAR tanks, bots and hovers climb steeper ground than in Zero-K, so more of the map turns green. Switching the game runs the checks again and keeps your edits.
- **Start boxes for BAR:** BAR takes start boxes from its lobby, so after a build the app shows the `!addBox` commands for the host to paste into the battle room chat.
- **Website** with downloads, screenshots and all templates: https://scuide.github.io/atlas-map-forge/

## Known limits (BAR)

- Size, type and description in BAR's map list stay empty: BAR fills them only for maps in its online map database.
- Chicken defence templates are Zero-K only (BAR has its own Raptors and Scavengers).
- For multiplayer, other players need the map file too: BAR downloads maps automatically only from its own map server.

## Good to know

- Maps are named `Forge <title> v<version>`. When you change a map, raise the version number before you share it.
- Zero-K: uploaded maps are "unsupported" on zero-k.info until the Zero-K team approves them; until then they can be played in passworded rooms.
- This is a pre-release: please report problems and ideas in the [issues](https://github.com/Scuide/atlas-map-forge/issues).
