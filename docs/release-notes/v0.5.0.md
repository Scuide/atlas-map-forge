**Pre-release 0.5.0: the map editor.** Atlas Map Forge makes complete, playable Zero-K maps from templates. With this version you can also change a generated map by hand before you build it: shape the terrain, paint the ground, place trees and rocks, and move every metal spot, vent, start point and start box. Symmetry and the checks are kept for every edit.

## Download

- **Windows:** `AtlasMapForge.exe` below: one file, no installation and no Python needed. If you have 0.4.22, just replace the old exe; your settings and project files stay.
- **Linux (new):** `AtlasMapForge-linux-x86_64.tar.gz` below: unpack it and start `./AtlasMapForge`. The app opens in your web browser. Built on Ubuntu 22.04, so it runs on most current 64-bit distributions (glibc 2.35 or newer). Zero-K installed through Steam is found automatically.

The Windows program is not code-signed yet, so Windows SmartScreen will say "Windows protected your PC". Click **More info**, then **Run anyway**. Every program is built and tested automatically on GitHub from the public source code in this repository.

## New in 0.5.0

- **Terrain tools:** brush with raise, lower, flatten (to a target height, Alt+click picks it), smooth, noise and terrace; a ramp from A to B; a stamp that copies a piece of terrain and pastes it turned, mirrored or blended.
- **Painting:** paths, concrete, scorch marks and lava crust, with an eraser, polygon fill and height-band fill. The paint shows in the preview and in the built map.
- **Trees, rocks and wrecks:** add or remove them in a circle with a chosen density.
- **Selection:** drag a rectangle to pick several metal spots, vents and start points, then move or delete them together. A live metal balance shows whether every team gets the same.
- **Edit list:** every action in order; click one to see where it was, switch it off and on, or delete it. Undo and redo work for everything.
- **Views:** zoom up to 8x, contour lines, a slope map (which units can climb where) and a rotatable 3D terrain view.
- **Help:** press **?** for all tools and keyboard shortcuts. While an edit is applied, "Updating preview" shows in the map.
- **5 new templates** (30 in total): Crater Basin, Fortress Front, Peninsula, Inland Sea and Island Continents.
- Every edit follows the map's symmetry (mirror or rotation, including free-for-all) and is saved in the `.forge.json` project file.

## Good to know

- Maps are named `Forge <title> v<version>`. When you change a map, raise the version number before you share it.
- Uploaded maps are "unsupported" on zero-k.info until the Zero-K team approves them; until then they can be played in passworded rooms.
- Lava crust paint is a look only; it does not hurt units.
- This is a pre-release: please report problems and ideas in the [issues](https://github.com/Scuide/atlas-map-forge/issues).
